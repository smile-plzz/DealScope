# Engineering decisions — 20 October 2026

1. **Baseline:** GitHub repository `smile-plzz/DealScope` existed but was empty. Implement a new Next.js App Router/strict TypeScript application; retain supplied instructions.
2. **Release scope:** limited beta, as explicitly permitted by the handoff when live source verification is unavailable. Store-wide discovery remains incomplete; it is not disguised by demo data.
3. **Storage:** browser-local sessions and preferences; no database or Supabase integration. This follows the handoff's safe-local-history option and avoids anonymous-session RLS risks. No placeholder migrations. History is capped at 30 sessions × 50 offers and expires from display after 30 days; next save prunes expired records.
4. **Synchronous APIs:** operations finish within the request. No background work after responding. Search returns its results immediately; browser-local result pages remove the need for server polling, session authentication or `/api/search/:id`. See API deviation notes.
5. **Evidence:** browser displays source extraction returned by our API. It is not cryptographically attested and is not an export verification system. The stateless compare API downgrades client-supplied claims to manual. Public/shared comparisons are not supported.
6. **AI:** optional, disabled by default; no fixed model/free-tier assumption. Explicit consent per input. Two calls maximum, with schema-only repair; no paid provider fallback. Unknown model access falls back to text.
7. **Seller access:** exact host allowlist and current robots check, not arbitrary crawling. Star Tech opt-in only; Ryans excluded; other sources manual-only. Policy observations do not imply licensing or partnership.
8. **Security:** HTTPS-only, DNS-address pinning, reject redirects, fail-closed content and byte limits. Do not route seller fetching through generic proxies because that would weaken IP pinning. Restricted execution environments can therefore block live verification.
9. **Comparison:** unknown fees/stock/condition and stale evidence disqualify confirmed cheapest. Manual totals are useful but unverified. If condition is “any,” new offers alone are ranked together; used/refurbished remain visible separately. Seller assurance points remain zero without a verified source.
10. **UI:** custom CSS with Lucide icons, locally bundled OFL-licensed Noto Sans Bengali for Bangla/taka glyphs, and no remote fonts/images. This departs from the recommended Tailwind stack without changing requirements; it reduces tooling and external dependencies. Responsive sidebar/workspace layout, mobile layout and accessible form labels.
11. **React hydration:** browser-local state is read in bounded mount effects after SSR. Targeted lint rule comments explain that external-storage hydration; other hooks/lint rules remain active.
12. **Operations:** per-instance in-memory cache, cooldown and throttling are best-effort in serverless deployments. They are not distributed security/cost controls. AI stays off until the operator sets provider limits and access protection, or implements a durable limiter.
13. **Publishing:** source delivery to the supplied repository is authorized by “Complete this.” Public hosting needs the explicit external-publishing approval required by the attached handoff. Prepare a reviewable candidate first; do not create an unrelated Sites project.
14. **Browser tooling:** use a pinned available Playwright distribution when the newest Chromium download is invalid in this environment. Report actual test results, not installation attempts as passes.
