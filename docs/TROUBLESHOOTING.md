# Troubleshooting

| Symptom                                                 | Action                                                                                                                                                                             |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI unavailable / HTTP 401                               | Check server-only key, AI_ENABLED, and configured model ID. Do not log secrets. Continue with text/manual mode.                                                                    |
| AI 429 or budget reached                                | Wait for cooldown; check account quota and provider limits. Do not rotate keys to evade limits. Manual mode remains available.                                                     |
| Image not identified                                    | Use supported JPEG/PNG/WebP ≤8 MB and ≤20 MP; browser resizes. Check vision-model access and consent, or describe the product.                                                     |
| Facebook Reel gives no product                          | Expected fallback: add a screenshot or description. The app does not watch or download Reels.                                                                                      |
| Seller extraction unavailable                           | Manual-only by default. Only opt-in exact Star Tech product paths are considered, with current robots permission. No arbitrary source proxy.                                       |
| Source blocked, wrong content type, redirect or timeout | Do not bypass protection. Open seller directly and record details manually; source circuit breaker resets after one minute.                                                        |
| Cheapest cannot be verified                             | Need exact/likely match, known condition/current stock, fresh seller evidence for item/shipping/mandatory fees and same delivery area. Manual entries remain unverified.           |
| Unknown shipping despite entered amount                 | Check delivery area matches quote area and other mandatory fees are specified. Blank fees are unknown.                                                                             |
| Offer excluded                                          | Check model, size, variant, quantity, condition and required/excluded attributes; an accessory is not the whole product.                                                           |
| History disappeared                                     | Confirm same browser/profile/origin; 30-day expiry/30-session cap apply. Clearing site data deletes it. Shared links do not transfer history.                                      |
| CORS/cross-origin POST rejected                         | Use same-origin frontend. Do not wildcard-enable credentials/CORS.                                                                                                                 |
| No Supabase settings                                    | Intentional: browser-local release does not use Supabase. No migrations/service keys are needed.                                                                                   |
| Build fails                                             | Use Node 22.14+ and `npm ci`; run typecheck/lint. No API credentials are needed for build.                                                                                         |
| Playwright archive invalid                              | Check download accessibility; use the pinned distribution and `npx playwright install --with-deps chromium`. Do not report browser tests as passing if browser installation fails. |
| Offline                                                 | Reconnect; the service worker caches help only, not API or price data.                                                                                                             |
