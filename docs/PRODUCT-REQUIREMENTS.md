# Implemented requirements and acceptance

The original handoff remains the intended long-term product. This release is its explicitly allowed limited-beta outcome.

| Journey                   | Current behavior                                                                                                          | Verification                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| Description to comparison | Confirm editable identity, conditions, quantity and requirements; empty results never manufacture offers                  | Unit/integration and browser suite  |
| Product/Facebook URL      | Validate HTTPS; opt-in exact-host extraction or actionable manual fallback; Facebook fallback without pretending to watch | URL/route tests and browser suite   |
| Screenshot                | Local resize, explicit AI consent, server decode/signature validation, optional vision; description fallback              | Image/AI tests and browser suite    |
| Collect manual offers     | Enter seller, price, fees, variant, condition and policy notes; all remain unverified                                     | API and browser suite               |
| Cheapest/value            | Deterministic eligibility, independent scores, reasons, unknown fees, source timestamps and stale labels                  | Comparison suite                    |
| Alternatives              | Exact/likely/similar/rejected sections; accessory, quantity, condition and required-feature protections                   | Matching suite                      |
| History/privacy           | Save, reopen, export, delete or clear browser-local comparisons; no stored screenshots                                    | Browser suite                       |
| Preferences               | Delivery area and theme persist; changing result area invalidates old shipping quotes                                     | Browser and total-cost tests        |
| Access and install        | Mobile/desktop layout, labeled keyboard controls, manifest/icons, offline help                                            | Browser suite plus production build |

## Not satisfied as a full live release

Automatic discovery across Bangladesh merchants; live extraction proof on three products across two sources; Mistral account/model/free-plan verification; comprehensive category-specific matching; global distributed rate/cost budget; authenticated shared histories; production hosting. These remain explicit release gaps, not undocumented shortcuts.
